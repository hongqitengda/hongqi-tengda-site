HQTD V12.4 直接覆盖版
======================

使用方法：
1. GitHub Desktop 先 Fetch/Pull 最新 main。
2. 解压本 ZIP。
3. 把 assets 和 customer-portal 两个文件夹直接复制到 G:\hongqi-tengda-site，选择覆盖。
4. 回 GitHub Desktop：Commit → Push origin。

本版没有 APPLY、BAT、Python 安装脚本。
本版不包含 sitemap.xml，不会修改 sitemap.xml。

功能：
- EN / FR / ES / AR / RU 项目查询页进一步消除中文回退显示。
- 客户中心增加 EN / FR / ES / AR / RU 前台界面翻译。
- 非中文语言提交时，项目 ID / 项目名 / 板块 / 分类等结构化字段按中文 catalog 规范化后送后台。
- 客户自己填写的需求描述、备注、联系人等原文保持原样，不做机器翻译。
- 繁体中文保持现有逻辑。

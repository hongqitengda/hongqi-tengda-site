高端材料表征｜最终干净覆盖包

本包是重新整理的干净版本，不是在 V6 上继续叠补丁。

【最终结构】
首页：
表征&检测三张代表卡 → 更多检测方向横条 → 高端材料表征与原位分析 → 首页后续原有模块

材料表征 / 环境检测页：
SEM / HPLC / EIS → 更多检测方向横条 → 高端材料表征与原位分析 → CATEGORIES / 表征&检测分类 → 环境代表性检测项目 → 后续内容

【顶部导航】
不新增“高端表征”一级导航。
仍只保留原来的“材料表征 / 环境检测”。
本包会用干净版 bilingual-navigation.js 覆盖此前遗留的“自动增加高端表征导航”代码。

【浮动窗口】
与网站现有高端计算 / 环境检测专题保持同一视觉体系。
宽屏 6 栏；普通桌面 4 栏；移动端 2 栏。
仅首页显示高端表征专题浮窗，避免内页到处漂浮造成混乱。

【单项订单】
专题区和浮窗每项都有：
查看详情 / 加入清单 / 单项提交

高端表征专题详情页中的具体技术卡也自动增加：
加入需求清单 / 单项提交此项

单项提交会清空高端表征组合需求，只携带当前 FX 项进入 demand-list.html，
避免“点一个项目却把全部高端表征一起提交”。

【Catalog】
保留中英文高端表征检索资源。
不机械修改“材料表征 124”的统计数量，避免与原有 TEM/XPS/AFM/XRD 项重复计数。

【使用】
1. GitHub Desktop 先 Fetch / Pull。
2. 解压本包。
3. 将包内文件按目录直接复制到仓库根目录并覆盖。
4. GitHub Desktop 检查 Changes。
5. Commit → Push。

不需要 PowerShell，不需要 PATCHES。
